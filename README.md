# Career Matcher

A career recommendation and skill-gap system built with React, Spring Boot, FastAPI, O*NET, embeddings, ChromaDB, and an LLM-based guidance layer.

## Project structure

- `backend/` — Spring Boot application
- `ml-service/` — FastAPI ML service
- `frontend/` — React/Vite frontend
- `data/onet/` — O*NET source data
- `docs/` — architecture and API contracts

## Current milestone

Phase 0 project skeleton. The next step is verifying all three services and then downloading/inspecting O*NET data.
